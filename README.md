# cohesion-benchmarks

Benchmarks for [Cohesion](https://github.com/assimalign/cohesion).

| Suite | What it measures |
|---|---|
| [`database/`](database/README.md) | The Cohesion SQL, Documents and Graph engines against PostgreSQL, SQL Server, MongoDB, RavenDB and Neo4j, on roughly 10 GB of generated data per model. **Paused before the full-scale runs — see [STATUS](database/docs/STATUS.md).** |
| `benchmarks/` | The original per-library BenchmarkDotNet micro-benchmarks (scaffold; unrelated to the database suite). |
