# Cache allocation results

Local Windows ARM64 investigation on 2026-10-21, starting from cohesion `c2b25e4ac` and
cohesion-benchmarks `7a6aa1a`. The after implementation lazily creates entry collections and
copies callbacks into an exact array. The candidate also fixes stale token callbacks (#1680).
No benchmark name or committed package pin changes.

Ordinary, TTL and sized replacement writes allocate **304 B instead of 400 B** (24% less).
Median timing changes are small (0.97-0.99x), so this is an allocation improvement, not a
claim of higher throughput. Microsoft.Extensions comparison methods remain at 104 B.

[COMPARISON.md](COMPARISON.md) is generated by `scripts/Compare-Benchmarks.ps1`; `before/`
and `after/` contain the unedited full BenchmarkDotNet reports.

Machine: Windows 11, Snapdragon X X1E80100, .NET SDK 10.0.402 / runtime 10.0.13 ARM64,
BenchmarkDotNet 0.15.8, in-process toolchain. One launch, three warmups and eight measured iterations.
Packages: `10.0.0-preview.1.perf.before` and `10.0.0-preview.1.perf.after`, locally packed from
the isolated cohesion worktree via `CohesionPatchVersion`. Neither version is published.

The temporary runner at `.artifacts/performance/src/PerformanceIteration.Benchmarks.csproj`
links the existing benchmark classes and consumes NuGet packages only. A temporary NuGet config
maps Cohesion to the local package directories, without editing `nuget.config`. The exact selection:

```powershell
dotnet run -c Release --project .artifacts/performance/src/PerformanceIteration.Benchmarks.csproj `
  -p:CohesionPackageVersion=<before-or-after-version> -p:RestoreConfigFile=<local-feed-config> -- `
  --profile ci --filter '*MemoryCacheBenchmarks.Set' '*MemoryCacheAccessBenchmarks.Set*' `
  '*KeyBenchmarks*' '*PathBenchmarks*' '*GlobBenchmarks.IsMatch' '*RoutePathBenchmarks*' `
  --warmupCount 3 --iterationCount 8 --artifacts <output>
```

The selection includes the other areas in this iteration; this folder preserves only cache reports.
The full affected cache suite passed (65 tests). NativeAOT native linking could not be completed
on this machine because ARM64 C++ linker tools are missing.
